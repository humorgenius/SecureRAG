How it works工作原理

Three steps, zero data leaving the tab三步完成，数据一步都不出标签页

Everything below happens in your browser's own memory. You can verify it yourself in DevTools → Network.下面每一步都发生在你浏览器的内存里。你可以随时打开开发者工具 → Network 自行验证。

STEP 01

Drop your files拖入文件

Drag & drop or click to select. PDF, DOCX, TXT, Markdown, CSV. Up to 40 files / 25 MB each — limits are shown before you start.拖拽或点击选择。支持 PDF、DOCX、TXT、Markdown、CSV。最多 40 份、单份 25MB——限额在上传前就明确写出。

File API → ArrayBuffer
STEP 02

Local indexing本地建立索引

Text extraction, structure-aware chunking and vector embedding run in a Web Worker, with live progress. Nothing is transmitted — the only network call ever is the model download.抽取文本、结构感知分块、向量嵌入都在 Web Worker 里执行，进度实时可见。全程不发送任何内容——唯一的网络请求是模型下载。

Worker · 512-dim vectors · IndexedDB
STEP 03

Ask & trace提问与溯源

Every answer carries numbered citations. Click one to jump to the exact paragraph — page number included for PDFs. Export the whole session when you're done.每条回答都带编号引用。点击即可跳到原文对应段落——PDF 还能定位到页码。结束后可导出整段问答记录。

FAQ

Questions we get asked a lot被问得最多的问题

Can I really verify that nothing is uploaded?我真的能验证没有上传吗？

Yes. Open DevTools → Network before you add a file. You will see the model weights download once; after that, adding documents and asking questions produces zero requests. The in-app Network shield shows the same list without DevTools.可以。在添加文件前打开开发者工具 → Network。你会看到模型权重下载一次；此后添加文档、提问都不会产生任何请求。站内的「网络盾牌」面板也能直接看到同一份列表，不必开开发者工具。

Which file formats are supported?支持哪些文件格式？

PDF (with a text layer), DOCX, TXT, Markdown, CSV, HTML and JSON. Legacy .doc is not supported — convert it first. Scanned PDFs need OCR before uploading; we detect this and tell you instead of silently returning nothing.PDF（需含文字层）、DOCX、TXT、Markdown、CSV、HTML、JSON。旧版 .doc 不支持，请先转换。扫描件 PDF 需先做 OCR；我们会检测并明确提示，而不是悄悄返回空结果。

Will answers be as good as a cloud AI?回答质量能比得上云端 AI 吗？

Retrieval quality is comparable, because it is the same class of embedding + vector search. Wording is weaker unless you enable the local generation tier. Our benchmark page shows real outputs side by side, including where we lose.检索质量接近，因为用的是同一类嵌入 + 向量检索方案。措辞会弱一些，除非开启本地生成档。对比页会并排展示真实输出，包括我们输在哪里。

How much memory does it need?需要多少内存？

Roughly 1.5 MB of RAM per 1,000 chunks plus the model. A 4 GB machine handles a few hundred pages comfortably. Mobile browsers are stricter — we cap collections there and say so.大约每 1000 个文本块占用 1.5MB 内存，另加模型本身。4GB 内存的机器处理几百页文档很轻松。移动浏览器限制更严，我们会自动降低上限并明确告知。
