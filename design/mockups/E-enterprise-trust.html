Document intelligence that runs on your machine, not on someone else's. 文档智能跑在你的机器上，而不是别人的服务器上。

SecureRAG is a static website with a full retrieval-augmented generation pipeline inside the browser: parsing, chunking, embedding, hybrid retrieval and cited answering. No backend, no accounts, no upload — and you can verify that claim in your own network tab in under a minute. SecureRAG 是一个静态网站，浏览器内包含完整的检索增强生成管线：解析、分块、向量化、混合检索与带引用的回答。没有后端、没有账号、没有上传——而且你可以在自己机器的网络面板里，一分钟内验证这句话。

Capabilities能力

Everything a serious document workflow needs — minus the data transfer严肃的文档工作流需要的都有，除了数据传输那一步

Zero-upload architecture零上传架构

No API endpoint exists to receive a document. The engine is JavaScript running against your own files in browser memory, persisted in your own IndexedDB.不存在能接收文档的 API 接口。引擎就是 JavaScript，读取浏览器内存里你自己的文件，持久化在你自己的 IndexedDB 中。

Verifiable in DevTools → Network开发者工具 → Network 可验证

Multi-document collections多文档合集

Group by matter, rename, pause, delete, re-index. Ask across the whole library or scope a question to a specific subset at ask-time.按事项分组、重命名、暂停、删除、重建索引。可全库提问，也可在提问时把范围限定到特定子集。

Up to 40 files · 20,000 chunks最多 40 份 · 2 万个块

Paragraph-level citations段落级引用

Every answer sentence maps to a numbered source, with the original sentence highlighted in place. PDFs carry page and section; Markdown and Word carry the heading path.回答中的每一句都对应编号来源，原句会在原位高亮。PDF 标注页码与章节，Markdown 与 Word 标注标题路径。

Click to jump, not just to scroll可点击定位，不只是滚动

Offline operation离线可用

Application shell and model weights are cached by a service worker. Air-gapped laptops, flights, restricted networks — the tool keeps working.应用外壳与模型权重由 Service Worker 缓存。物理隔离的内网笔记本、飞机上、受限网络里，工具照常可用。

Installable as a PWA可作为 PWA 安装

Strictness control严格度控制

Documents-only mode returns "not found in your documents" instead of guessing. Inference mode may summarise across chunks but flags every inferred statement.「仅依据文档」模式在找不到时返回「文档中未找到」而不是猜；「允许推理」模式可跨片段归纳，但会标注每一条推断。

Four claims we are willing to be tested on四条经得起你当场检验的说法

Privacy posture隐私立场

Test it yourself你可以自己验

01No document transmission不传输文档

Your files are read via the File API into memory. There is no upload code path in the application, and no endpoint that could accept one.文件经 File API 读入内存。应用里不存在上传代码路径，也不存在能接收上传的接口。

02No training on your data不用你的数据训练

Models run inference only. No gradients are computed, no feedback loop exists, and no content is retained outside your browser storage.模型只做推理。不计算梯度、不存在反馈回路，除你浏览器的存储外不保留任何内容。

03One disclosed third party唯一披露的第三方

Model weights are fetched from a public model host. That request carries no document content, no question and no identifier — only the model file name.模型权重从公开模型托管站拉取。该请求不携带文档内容、问题和任何标识，只包含模型文件名。

04Deletable by you, instantly你可即时彻底删除

Clearing site data removes every chunk, vector and conversation. We hold no copy because we never had one.清除站点数据即删除全部块、向量与对话。我们手上没有副本，因为从来就没有过。

FAQ

Questions from people with sensitive documents来自手握敏感文档的人的问题

Can I verify the no-upload claim without trusting you?我能否在不信任你们的前提下验证"不上传"？
Yes, and we would rather you did. Open DevTools → Network, clear the log, then add a document and ask several questions. The only request you should see on a first visit is the model weights. Repeat with the network disabled: it keeps working. The in-app shield panel reports the same records without DevTools.可以，而且我们更希望你去验。打开开发者工具 → Network，清空日志，然后添加文档并连问几个问题。首次访问你唯一应看到的请求就是模型权重。之后把网络断开重试：它照常工作。站内盾牌面板无需开发者工具也能显示同一份记录。
What is the one third-party request, exactly?那唯一一个第三方请求，具体是什么？
A GET for the model file from a public model host (HuggingFace or a mirror). The request contains the file name and nothing else — no document, no question, no cookie identifying you. The model page lists every file by name and size so you can check what lands on your machine.向公开模型托管站（HuggingFace 或镜像）发起的一次模型文件 GET。请求里只有文件名，没有文档、没有问题、没有能标识你的 Cookie。模型页会列出每个文件的名称与体积，你可以核对到底下到了什么。
Is this suitable for regulated or confidential material?它适合受监管或机密材料吗？
Architecturally it removes the third-party transfer problem, because no transfer occurs. Whether that satisfies your specific obligations is a judgement only you and your compliance team can make — we provide the technical facts (data flow, storage location, deletion method) in the security page so that judgement can be made quickly.从架构上讲，它消除了"第三方传输"这个问题，因为根本没有传输。至于这是否满足你的具体合规义务，只能由你和你的合规团队判断——我们在安全页里提供了技术事实（数据流、存储位置、删除方式），让你能快速做出判断。
How does the site fund itself?这个网站靠什么维持？
Labeled display advertising, capped at three units per page and never placed inside the chat workspace or above the primary action. There is no subscription, no data sale, and no tracking beyond what the ad network itself requires — with a consent gate before any ad script loads.明确标注的展示广告，每页最多三个，绝不放进聊天工作区，也不压在主要操作上方。没有订阅制、不卖数据、除广告网络自身必需之外没有额外追踪——且广告脚本加载前会有同意门。
