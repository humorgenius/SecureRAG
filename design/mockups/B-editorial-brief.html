Technical brief技术说明 2026-09 · rev 3.1 Reading time 6 min阅读约 6 分钟 No data leaves the browser数据不出浏览器

A document question-answering system that runs entirely on the reader's machine. 一个完全运行在读者机器上的文档问答系统。

SecureRAG turns your browser into a retrieval-augmented generation engine: it parses, chunks, embeds and searches your documents locally, then answers with citations that point back to the paragraph they came from. No server, no account, no upload. SecureRAG 把你的浏览器变成一台检索增强生成引擎：解析、分块、向量化、检索全部在本地完成，回答附带可回溯到原始段落的引用。没有服务器，没有账号，没有上传。

Abstract摘要

SecureRAG is a static website. It ships no backend service and makes no inference API calls. Documents you add are read through the File API into browser memory, split into structure-aware chunks, embedded with a small quantised transformer model1, and indexed in IndexedDB. Retrieval combines dense vector similarity with a BM25 keyword pass, fused by reciprocal rank fusion2.SecureRAG 是一个静态网站，不包含任何后端服务，也不调用任何推理接口。你添加的文档经 File API 读入浏览器内存，按结构感知规则分块，用小型量化 Transformer 模型生成向量1，索引存入 IndexedDB。检索同时使用稠密向量相似度与 BM25 关键词召回，通过倒数排名融合合并结果2。

The only outbound network request the application ever makes is the one-time download of model weights, which contain no user content. Everything else — including the answer generation step — happens on your CPU or GPU.整个应用唯一的外发网络请求，是一次性的模型权重下载，其中不含任何用户内容。其余全部环节——包括回答生成——都发生在你的 CPU 或 GPU 上。

01

Method实现方法

Four stages, all client-side. Each one is inspectable in the browser's own developer tools.四个阶段，全部在客户端。每一步都能在浏览器开发者工具里查到。

1

Ingestion文档摄取

Drag and drop PDF, DOCX, TXT, Markdown or CSV. Magic-byte sniffing decides the parser, not the file extension. Limits — 40 files, 25 MB each, 200 MB total — are stated before you drop anything.拖入 PDF、DOCX、TXT、Markdown 或 CSV。用魔数嗅探决定解析器，而不是只看扩展名。限额——40 份、单份 25MB、总计 200MB——在上传前就已写明。

File API → ArrayBuffer
PDF.js · mammoth · custom
2

Chunking & embedding分块与向量化

Documents are split along heading boundaries first, then paragraphs, then sentences — 700 characters with 15% overlap. Each chunk is embedded in a Web Worker and stored as a normalised Float32 vector.先按标题层级切，再按段落、再按句子，每块约 700 字符、15% 重叠。每块在 Web Worker 中生成向量，以归一化 Float32 存储。

512-dim · q8 ONNX
Worker batch = 16
3

Hybrid retrieval混合检索

Vector search finds paraphrases; BM25 catches exact identifiers like contract numbers and model codes. Reciprocal rank fusion merges both lists, and MMR removes near-duplicate chunks before they reach the prompt.向量检索负责语义近似，BM25 负责合同编号、型号这类精确标识符。倒数排名融合合并两个列表，MMR 在进入提示词前剔除近重复片段。

top-k 6 · MMR λ 0.7
threshold filtering
4

Answering生成回答

Two tiers. The default extractive tier selects and stitches source sentences — instant and always quotable. The optional generation tier runs a 0.5B–1.5B local model, with a strict mode that refuses rather than guesses.两档可选。默认抽取式从源句中挑选并拼接，即时且句句可引；可选生成档运行 0.5B–1.5B 本地模型，严格模式检索不到时直接拒答而不是猜。

extractive (25 MB)
generative (400 MB–1 GB, opt-in)
02

What you get你能得到什么

Zero-upload guarantee零上传保证

Not a policy promise — an architectural fact. There is no endpoint to POST to, and a live network panel lists every request the page makes.这不是政策承诺，而是架构事实：根本没有可以 POST 的接口，站内还有一块实时网络面板列出页面的每一次请求。

Citation to paragraph引用到段落

Answer sentences link to the exact source passage, with page and section for PDFs and heading path for Markdown and Word.回答中的句子可跳到确切原文段落；PDF 标注页码与章节，Markdown 与 Word 标注标题路径。

Collection management文档集管理

Group by matter or project, rename, disable a document without deleting it, re-index after switching models, scope a question to a subset.按案件或项目分组、重命名、临时停用而不删除、换模型后重建索引、把问题限定在子集内。

Offline operation离线可用

The app shell and model weights are cached by the service worker. Verified in airplane mode; nothing breaks.应用外壳与模型权重由 Service Worker 缓存。飞行模式下实测可用，功能不受影响。

Adjustable strictness严格度可调

Documents-only mode answers "not found" when the corpus is silent. Inference mode summarises across chunks but marks every unsourced sentence.「仅文档」模式在语料沉默时回答「未找到」；「允许推理」模式可跨片段归纳，但每个无来源的句子都会被标注。

Export & audit导出与审计

Export a session as Markdown, JSON or plain text — including the model used, the strictness setting and every citation, so a colleague can reproduce it.会话可导出为 Markdown、JSON 或纯文本，包含所用模型、严格度设置与全部引用，同事据此可复现。

04

Questions常见问题

How can I verify the no-upload claim myself?我如何自行验证"不上传"？
Open DevTools → Network, then add a document and ask three questions. You will see a single model-weights request on first use and nothing afterwards. The in-app network panel shows the same records without DevTools.打开开发者工具 → Network，然后添加一份文档并连问三个问题。你只会看到首次使用时的一次模型权重请求，此后没有任何请求。站内网络面板也能看到同样的记录。
Is my document used to train anything?我的文档会被用于训练吗？
No, and it could not be. Models are downloaded once and run without any training step; no gradients are computed and no data is transmitted. Clearing your browser storage erases every trace.不会，也不可能。模型只下载一次并以推理方式运行，不进行任何训练步骤，不计算梯度，不传输数据。清空浏览器存储即抹除全部痕迹。
What about scanned PDFs?扫描件 PDF 怎么办？
We detect the missing text layer and say so, rather than returning empty results. The OCR guide walks through preparing a scanned file with an offline OCR tool before importing it.我们会检测到缺少文字层并明确提示，而不是返回空结果。OCR 指南里介绍了如何先用离线 OCR 工具处理好扫描件再导入。
Which devices are capable?什么设备能用？
Any Chromium, Firefox or Safari release from the past two years handles the default tier. The generation tier wants WebGPU for usable speed; without it we run on CPU and say plainly that it will be slow.最近两年内的 Chromium、Firefox、Safari 都能跑默认档。生成档想要流畅需要 WebGPU；没有的话走 CPU，我们会直接说明会慢。

Load one file. Watch the network tab stay quiet.导入一个文件，然后盯着网络面板看它保持安静。

That silence is the product.那份安静，就是这个产品。
