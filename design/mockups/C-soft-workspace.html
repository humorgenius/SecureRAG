FAQ

The things people ask before trusting it人们在信任它之前会问的问题

How do I know it isn't secretly uploading?我怎么知道它没偷偷上传？
Three ways: our built-in network panel, your browser's own DevTools → Network tab, and the fact that the site is static — there is literally no backend endpoint to receive anything. We also publish the engine source so the parsing and embedding code can be read.三条路：站内的网络面板、你浏览器自带的开发者工具 → Network、以及这个网站本身是静态的这一事实——根本不存在能接收数据的后端接口。引擎源码也会公开，解析与向量化代码都可以读。
What happens to my index if I close the tab?关掉标签页，索引会怎样？
It stays in your browser's IndexedDB, so your next visit is instant. Clearing site data (or using private mode) wipes it — which is also how you clean up.它会留在你浏览器的 IndexedDB 里，下次打开就是即时的。清除站点数据（或用隐私模式）就会抹掉——这也正是清理方式。
Which files can't it handle?哪些文件处理不了？
Password-protected and scanned PDFs (no text layer), legacy .doc files, and anything over 25 MB. In each case we say exactly what went wrong and suggest a fix instead of failing silently.加密 PDF 和扫描件 PDF（无文字层）、旧版 .doc、以及超过 25MB 的文件。这三种情况我们都会明确说明原因并给出建议，而不是默默失败。
Is it really free? Where's the catch?真的免费？坑在哪？
No catch on the tool itself: it runs on your hardware, so there's nothing for us to bill. The site is funded by clearly labeled display ads kept outside the chat workspace. No paywall, no data sale — we couldn't sell your data even if we wanted to.工具本身没有坑：它跑在你自己的硬件上，我们也没什么可收费的。网站靠明确标注、且不会出现在聊天区内的展示广告支撑。没有付费墙，不卖数据——就算想卖也无从卖起。
